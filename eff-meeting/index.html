議題 1TOYO LINK と ルートミー — 説明とトライアルの進め方

1-1. TOYO LINK 🧺 — 豊洲の卸どうしをつなぐ「在庫の過不足マッチング掲示板」

デモ公開中 「突発で在庫が足りない」「キャンセルで余った」を、いつもの電話仲間だけでなく豊洲の仲間内に掲示で共有。 電話で詰めた取引を記録に残して月末にまとめて精算する仕組みです。配送・人手の相談（持ってくよ／持ってける？）も掲示できます。

できること内容
掲示板「求む（赤）」「出す（緑）」「持ってくよ（青）」「持ってける？（黄）」「相談（紫）」の5種類を色分け掲示。連絡先は常時表示＝最後は電話で詰めるいまのやり方のまま
成立と記録数量・単価を入れて双方がワンタップ確認 → 取引として記録。言った言わないを防止
月末精算相手ごと・売り買い方向別に明細を自動集計。そのまま請求項目に使える（月末締めロック付き）
信用が見える実名確認バッジ・取引実績・応答速度・フォロワー数で「安心して声をかけられる相手」が分かる
朝イチ画面今朝の急募・出物・運搬余力・市場ニュース（毎朝自動更新）をひと目で
卸さがす検索業種（野菜／海鮮／乾物／配送業）やキーワードで相手を探せる

デモURL（スマホでそのまま触れます）：https://spicy-device.com/toyosu-relay/

現在は「デモ版」です
いま公開中のものは説明・体験用で、データは各端末の中だけ（会社をまたいだ共有はまだできません）。 実際に複数社で使う「共有版」（各社ログイン式）は設計済みで、ご意見をいただいてから本開発に入ります。

1-2. ルートミー（RoutMe）🚚 — 配送の「記録・締め・精算」をひとつにするアプリ

本番稼働中（ログイン式） 配送ドライバー・卸（荷主）・委託本部の三者が同じ画面でつながる配送管理アプリです。 旬彩坊様の配送管理から生まれ、高齢のドライバー・古いスマホでも使えることを最優先に作っています。

立場できること
ドライバー今日のルート表示・タップで配達完了・地図連携・配達写真の証跡・給油/経費記録・売上（歩合）の見える化
卸（荷主）店舗ごとの「本日注文あり/なし」を設定 → ドライバーのルートに自動反映。全ドライバーの進捗・完了時刻をリアルタイム確認
委託本部ルート割当・単価設定・日次の締め申請 → 承認 → 精算・コスト集計（Excel再入力をなくす）
安全・法令面点呼・アルコールチェック・運転日報・業務記録の作成と保存を支援（記録漏れは一覧で確認可能）
※ 記録の作成・保存を支援するもので、法令対応そのものを保証するものではありません
ヘルプ便積み残し・欠員時に「この便お願いできる人」を募集 → 引受 → 精算台帳に記録

ルートミー トライアルの進め方（案）

現在、旬彩坊様まわりで「受注 → ピッキング → 配送 → 完了 → 締め」を通しで検証する準備を進めています。eff様では次の小さな一歩から始められます。

1
ルート1本を登録：いまの配送先リスト（Excelでも紙でも）をお預かりし、こちらで一括登録（貼り付け登録機能あり・作業はお任せで大丈夫です）
2
1〜2週間の試運転：ドライバーさんは「配達したらタップ」だけ。事務所側は進捗画面を見るだけ
3
締めを1回体験：締め申請 → 承認 → 支払明細まで1サイクル回し、「いまのExcel・手書きと比べてラクか」を確認
4
判断：効果があれば本利用の範囲・条件をご相談（費用はトライアル結果を見てからで結構です）

議題 3お困りごと・手間に感じていることを教えてください

「どこが一番手間か」を教えていただくのが目的です。★印は特に伺いたい項目で、事前にメール等でご回答いただける場合はこの表をそのままお使いください。 当日は実際の帳票（注文メモ・納品書・請求書など）を見せていただけると、より具体的なご提案ができます。

A. 受注まわり（注文はどう入ってくるか）

✓質問回答メモ
☐★ 注文はどの手段で入りますか？（電話／FAX／LINE／メール／受発注サイト）それぞれの割合は？
☐★ 受注の締め時間と、直前の変更・キャンセルはどれくらいありますか？
☐受けた注文はどこに書き写しますか？（手書きメモ／Excel／システム）転記は何回発生しますか？
☐聞き間違い・書き間違いによる誤出荷は月に何回くらいありますか？

B. 出荷・配送まわり

✓質問回答メモ
☐★ 配送コース数・車両台数・ドライバーさんの人数（自社／外注の内訳）は？
☐ピッキング（積み込み）リストは誰がどう作っていますか？
☐配達完了の確認はどうしていますか？（受領印／電話／特になし）誤配・未着のトラブル頻度は？
☐ドライバーさんの点呼・日報・アルコールチェックは記録していますか？（紙／なし）
☐急な欠員・積み残しのとき、どうやってカバーしていますか？（仲間に電話？）

C. 請求・支払い・事務

✓質問回答メモ
☐★ 納品書・請求書は何で作っていますか？（手書き／Excel／販売大臣などのソフト）
☐★ 月末締めの請求業務に、毎月およそ何時間かかっていますか？何名で？
☐入金の確認（消込）はどうしていますか？未入金の管理で困ることは？
☐仕入れ側の伝票・請求書の処理はどうしていますか？（手入力の量）

D. 在庫・仲間内の融通（TOYO LINKに直結）
