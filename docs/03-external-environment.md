## 0. この章の結論

外部環境から、**機会が3つ、脅威が2つ**出た。うち1つは、これまでの設計を組み替えるだけの重みがある。

### 最大の発見：融資計画書の需要は「開業」ではなく「借換」で、いまピークにある

| | |
|---|---|
| 事実 | **2026年4月〜9月が、コロナ借換保証の返済開始の最後のピーク**（TSR）。本レポート執筆時点（2026年9月）はその渦中 |
| 事実 | コロナ借換保証・経営改善サポート保証はいずれも **「経営行動計画書」の作成が必須要件**（中小企業庁） |
| 事実 | しかも「金融機関との対話を通じて作成し、継続的な伴走支援を受ける」ことが要件に含まれる（中小企業庁） |
| 事実 | ゼロゼロ融資利用後の倒産は**業種別で飲食店が最多**、累計2,383件（TSR・2026年上半期時点） |

**つまり、いま全国の飲食店に「銀行に出す計画書を作らなければならない、しかも自力では作れない」という状況が同時発生している。**

これは藤谷が作ろうとしている「銀行に見せる計画表」の需要そのものだが、
**私がこれまで想定していた開業融資ではなく、借換・経営改善の計画書**である。
セグメントも緊急性も規模も違う。詳細は 5-2。

確信度: 高（制度要件と返済ピーク時期はいずれも一次情報で確認）

## 1. 政治・制度環境（Political）

### 1-1. 金融支援制度 ― いま動いている制度がユーザーの行動を強制している

| 制度 | 内容 | 出典 |
|---|---|---|
| **コロナ借換保証** | 2023年1月10日開始。**経営行動計画書の作成が必須**。要件は売上または利益率が5%以上減少、セーフティネット保証4号/5号の認定、金融機関の継続支援 | 中小企業庁 |
| 保証条件 | 限度額1億円／保証期間10年以内／据置5年以内／保証料0.2%（補助前0.85%） | 中小企業庁 |
| **経営改善サポート保証** | 経営サポート会議・中小企業活性化協議会等の支援で作成した再生計画の実施を保証する制度。2025〜26年に要件を拡充 | 中小企業庁 |
| **返済ピーク** | **2026年4月〜9月にコロナ借換保証の返済開始が最後のピーク** | TSR |

**示唆**: 「計画書を作らないと借換ができない」という**制度による強制需要**が発生している。
自発的な経営改善意欲に依存しないので、需要の確度が高い。確信度: 高

ただし後述（5-2）のとおり、この層の**支払能力には大きなばらつきがある**。

### 1-2. 労務・コスト側の制度圧力

- 最低賃金の継続的な引き上げ（年次）
- 物流2024年問題を経たコスト構造の変化が、食品卸を通じて飲食店の仕入価格に波及（農水省／業界紙）

（インボイス制度・電子帳簿保存法は既に定着期に入っており、新規の機会としては弱いと判断。確信度: 中）

### 2-2. コスト ― 価格転嫁できない構造が確定している

| 指標 | 数値 | 出典 |
|---|---|---|
| 仕入価格の上昇に直面している飲食店 | **94.6%** | 業界調査 |
| 販売価格を上げられた飲食店 | 64.9% | 業界調査 |
| → 自社で吸収している差分 | **約30ポイント** | 上記より算出 |
| **飲食業の価格転嫁率** | **28.7%（全業種で最下位クラス）** | 業界調査 |
| うち原材料費の転嫁率 | 47.3% | 同上 |
| うち**人件費**の転嫁率 | **32.0%** | 同上 |
| 値上げされた食品品目数 | 2025年 20,609品目／2026年4月までに3,593品目 | 業界調査 |

**示唆（ここが最も重要）**:
価格転嫁率28.7%ということは、**売価では利益が作れない**ことが構造的に確定している。
したがって飲食店が利益を出す手段は**コスト側（仕入・原価・人件費配分）しか残っていない**。

これは藤谷の実績領域（購買改善・仕入れ見える化・原価改善）と正面から一致する。
人件費の転嫁率が32.0%と特に低いのは、費目が複数メニューにまたがり配賦が難しいためで、
これも「数字を整理する」仕事の需要そのもの。確信度: 中〜高（単一系統の調査に依拠）

### 3-2. ゼロゼロ融資後の倒産

| 指標 | 数値 | 出典 |

| 2025年 ゼロゼロ融資利用後倒産 | 433件 | 東京商工リサーチ |

**示唆**: 倒産の77.3%が負債5,000万円未満の小規模事業者。
**この層は月額顧問料を払えない。** したがって「困っている飲食店が増えている＝市場機会」という
短絡は成立しない。困窮層と支払可能層を分けて考える必要がある（→ 5章）。確信度: 高

### 3-3. 多店舗展開の構造的な困難

二次情報の範囲だが、2店舗目で発生する課題は一貫して以下に収斂している。

1. **資金**: 物件・内装・厨房・仕入・人件費の初期投資を1店舗目の利益で賄えず、開業直後からキャッシュフローが厳しくなる
2. **人材育成**: 育成が追いつかず、サービス品質が落ちる
3. **立地選定**: 1店舗目の成功で過信し、調査不足のまま出店する
4. **管理業務の複雑化**: **店舗数が増えると紙での管理が現実的に難しくなる**

**示唆**: 4番目が藤谷の「あいだ」ツール群（店舗間フードリレー・店舗間ヘルプ・デシャップボード）の
需要そのもの。そして1番目が「銀行に見せる計画表」の需要。
**2店舗目という一点で、藤谷の持ち駒2種類が同時に必要になる。** 確信度: 中（二次情報のみ）

## 4. 技術・業界構造（Technological / Industry）

### 4-1. 食品卸売業の構造

| 事実 | 出典 |
|---|---|
| 1990年代以降、大手商社系列の再編・M&Aが活発化。上位には売上2兆円超の企業 | 業界調査 |
| **大手総合卸は機能・サービスでの差別化が困難**。大手小売の取引口座を巡り、価格と物流サービスレベルでシェア争い → **利益率を著しく低下させる要因** | 業界調査 |
| 物流2024年問題を経たコスト構造の変化。人手不足を補う自動化投資が不可欠 | 業界調査 |
| 資本力のある大手による再編がさらに加速する見通し | 業界調査 |

**示唆**: 大手が価格と物流で殴り合って利益率を落としている一方、
**中堅・中小の卸は「機能」で差別化するしか生き残る道がない。**
藤谷がクライアントA・クライアントC で作ってきたもの（在庫マッチング・朝の申し送り・仕入れレポート・
加盟店の商品登録代行）は、まさに中小卸が持てない「機能」にあたる。

これは「飲食店向けコンサル」より**競合が薄く、かつ相手の必要性が切実な市場**である可能性が高い。
確信度: 中（業界の一般構造としては確度が高いが、中小卸の投資余力は未検証）

## 5. 機会と脅威の整理

### 5-1. 機会（Opportunity）

| # | 機会 | 根拠 | 緊急性 | 確信度 |
|---|---|---|---|---|
| **O1** | **借換・経営改善の計画書需要**。2026年4〜9月が返済開始の最後のピーク、かつ経営行動計画書が制度上の必須要件 | 中小企業庁・TSR | **最高（いま）** | 高 |
| **O2** | **コスト側でしか利益が作れない構造**。価格転嫁率28.7%、仕入上昇94.6%に対し値上げ64.9% | 業界調査 | 高（継続） | 中〜高 |
| **O3** | **中小食品卸の機能差別化needs**。大手は価格・物流で消耗、中小は機能でしか残れない | 業界調査 | 中（構造的） | 中 |
| O4 | 2店舗目の管理破綻。店舗数が増えると紙管理が破綻する | 二次情報 | 中 | 中 |

### 5-2. 脅威（Threat）

| # | 脅威 | 根拠 | 影響 | 確信度 |
|---|---|---|---|---|
| **T1** | **困っている層ほど払えない**。倒産の77.3%が負債5,000万円未満の小規模 | 帝国データバンク | **大** | 高 |
| **T2** | 市場は単価上昇で伸びており、数量は伸びていない。客数減の業態もある | 日本フードサービス協会 | 中 | 高 |

**T1は本設計にとって最大の脅威**なので明示しておく。

「飲食店が困っている → 需要がある」は成立しない。
困窮の最先端にいる層（負債5,000万未満・小規模・個人店）は、**顧問料も制作費も払えない**。
O1の借換需要も同じ罠がある。借換が必要＝資金繰りが苦しい＝支払能力が低い、という相関が働く。

したがって**O1を取りにいくなら、支払える層をどう切り分けるかが設計の中心課題になる**（→ Ⅵ ターゲティング）。
